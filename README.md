# Shosu（処刑）

推理文字冒险游戏《魔法少女ノ魔女裁判》的二次创作应用。

## 版本 / Versions

- **Web Version (React)** - 位于 `web/` 目录，使用 React + TypeScript + Vite 构建的 Web 应用
- **Android Version (Original)** - 位于 `app/` 目录，基于 Kotlin 与 Jetpack Compose 的 Android 应用

## Web 版本快速开始

```bash
cd web
npm install
npm run dev
```

详见 [web/README.md](web/README.md)

## Android 版本

原 Android 应用基于 Kotlin 与 Jetpack Compose。
