# Shosu（処刑）

推理文字冒险游戏《魔法少女ノ魔女裁判》的二次创作的移动应用。
基于 Flutter 框架开发。

## 特性

- 跨平台支持（Android、iOS）
- 多语言支持（日语、中文、英语）
- 触觉反馈和音效
- 优雅的动画效果

## 开发

### 要求

- Flutter SDK 3.0.0 或更高版本
- Dart SDK 3.0.0 或更高版本

### 运行

```bash
flutter pub get
flutter run
```

### 构建

```bash
# Android
flutter build apk --release

# iOS
flutter build ios --release
```
